### 五、`pipeline/run_spatial_niche_analysis.py` 的前期修改（保留记录）

#### 5.1 Step 15 参数扫描修复（resolution → k）

**根本问题**：原始扫描使用 `resolution × quantile` 二维网格，但 Leiden `resolution` 仅决定聚类粒度，**不影响 `niche_score` 数值**，导致所有列 DEG 结果完全相同，热图无意义。

**修复方案**：改为 `k × quantile` 扫描，`k`（kNN 邻居数）直接影响邻域组成向量，进而影响 `niche_score` 和 DEG 结果：
- 横轴：`niche_high_quantile`（0.70 / 0.75 / 0.80 / 0.85）
- 纵轴：`k`（8 / 10 / 15 / 20 / 25）
- 颜色：FDR<0.05 且 log2FC>0.5 的 DEG 数量
- 选参标准：颜色最深且处于"高原"区域（与相邻格子结果相近）的参数组合为推荐

**代码改动**：
```python
# 原：
# resolution_list=(0.3, 0.4, 0.5, 0.6, 0.7)
# pivot = param_scan_df.pivot(index="resolution", ...)

# 改为：
k_list=(8, 10, 15, 20, 25)
pivot = param_scan_df.pivot(index="k", columns="quantile", values="n_sig_deg")
ax.set_ylabel("kNN neighbors (k)")
```

#### 5.2 Gini Index 文件生成保障

**问题**：`gini > 0.5` 阈值过严，FOXP3 等稀有基因（Gini ≈ 0.3~0.5）被过滤，且文件仅在结果非空时保存。

**修复**：
1. 阈值从 0.5 降至 **0.3**
2. **始终写出** `gini_score_genes.csv`（即使空文件也写出，保证路径可预期）

```python
# 原：
if gini > 0.5: ...
if not gini_df.empty:
    gini_df.to_csv(...)

# 改为：
if gini > 0.3: ...
gini_df = ranked.attrs.get("gini_df", pd.DataFrame(
    columns=["gene", "gini", "log2_fc", "mean_high"]
))
gini_df.to_csv(gini_out, index=False)  # 始终写出
```

### 七、HCC4R+CHC20 联合分析功能（新增）

#### 7.1 联合分析入口脚本 `run_joint_hcc4r_chc20.py`

**新增文件**：`code/run_joint_hcc4r_chc20.py`

**设计目的**：HCC4R 与 CHC20 两张切片经批次效应评估确认 batch effect 极小，适合联合分析以获得更大样本量和更高统计功效。

**分析流程**：
1. **Step 1**（`run_preprocessing.py → main_joint`）：用同一个 scRNA 参考训练一次 RegressionModel，得到统一 `cell_state_df`；分别对 HCC4R 和 CHC20 做 Cell2location 反卷积；合并两切片 spot 级结果，加 `obs["sample"]` 列标记来源
2. **Step 2**（`run_spatial_niche_analysis.py --per-sample-neighbors`）：基于合并后的联合 AnnData 进行空间免疫抑制生态位识别，启用 `--per-sample-neighbors` 确保空间邻域只在同一切片内建立

```bash
# 完整流程
python code/run_joint_hcc4r_chc20.py

# 仅 Step 1
python code/run_joint_hcc4r_chc20.py --step1-only

# 仅 Step 2
python code/run_joint_hcc4r_chc20.py --step2-only
```

#### 7.2 `run_preprocessing.py` 新增 `main_joint()` 函数

**新增函数**：`main_joint(path_scrna, path_sample_a, path_sample_b, sample_a_name, sample_b_name, output_dir)`

与 `main()` 的区别：
- 接受两切片路径（`path_sample_a` / `path_sample_b`，均为主切片，非主-验证关系）
- 使用 scRNA 参考与两切片的**三路共同基因子集**训练**一次** RegressionModel
- 分别对两切片做 Cell2location 反卷积
- 合并两切片 spot 级结果，添加 `obs["sample"]` 列（值为 `sample_a_name` 或 `sample_b_name`）
- 保存 `adata_vis_post_joint.h5ad`（合并结果）和各切片独立结果
- 生成 `spot_cell_proportion_joint.csv`（含 `sample` 列）和 `shared_genes_joint.txt`（三路交集）

#### 7.3 `run_spatial_niche_analysis.py` 新增 `--per-sample-neighbors` 参数及配套逻辑

**核心问题**：联合分析合并两切片后，物理空间不连续（HCC4R 和 CHC20 来自不同组织样本），若 kNN 邻域跨切片建立，会导致生物学意义错误的邻居关系（如 HCC4R 的边缘 spot 与 CHC20 的中心 spot 互为邻居）。

**新增参数**：

```python
parser.add_argument(
    "--per-sample-neighbors", action="store_true",
    help="联合分析模式下，限制空间邻域在同一切片（sample）内建立，"
         "不允许跨切片互为物理邻居。需要 adata.obs['sample'] 列。"
)
```

**新增函数**：

| 函数 | 功能 |
|------|------|
| `_build_knn_neighbors_per_sample(coords, sample_labels, k)` | 按切片分组构建 kNN 邻域，确保不跨切片建立邻居关系 |
| `_spatial_neighbors_per_sample(coords, sample_labels, radius)` | 按切片分组构建半径邻域，用于邻域均值特征计算 |

**运行时逻辑**：

```python
# 根据 --per-sample-neighbors 决定使用哪个邻域构建函数
sample_labels = adata.obs["sample"].values if per_sample else None
_knn_fn = _build_knn_neighbors_per_sample if sample_labels is not None else _build_knn_neighbors
_rad_fn = _spatial_neighbors_per_sample if sample_labels is not None else _spatial_neighbors
```

**影响范围**：邻域构建、邻域均值特征计算、Leiden 聚类、niche_score 计算、敏感性分析、参数扫描均使用 per-sample 版本。
