## 一、Step 15 参数扫描：从 resolution × quantile 改为 k × quantile

### 问题根因

原来的 `resolution × quantile` 二维扫描存在**根本性逻辑错误**，导致热图所有列（resolution）完全相同：

| 参数 | 对 niche_score 的影响 | 结论 |
|------|----------------------|------|
| `niche_high_quantile` | **直接影响**：控制阈值高低，niche_high 组大小随之变化 | ✅ 有效参数 |
| `Leiden resolution` | **无影响**：仅决定聚类粒度（n_clusters），niche_score 由邻域组成 Z-score 计算，与 resolution 无关 | ❌ 无效参数 |
| `k`（kNN 邻居数） | **直接影响**：邻域大小不同 → 邻域组成向量不同 → niche_score 不同 → DEG 不同 | ✅ 有效参数 |

**现象说明**：固定 k 时无论 resolution 如何变化，`_compute_neighborhood_composition` 用的是同一个 `neighbors_knn`，niche_score 向量完全一致，DEG 结果必然相同，热图每列都一模一样。

### 修复方案

将扫描轴从 `resolution` 改为 `k`（kNN 邻居数）：

- **纵轴（新）**：k = 8, 10, 15, 20, 25
  - 小 k（如 k=8）：邻域小，捕捉微观局灶性免疫聚集
  - 大 k（如 k=25）：邻域大，捕捉宏观区域性免疫浸润
- **横轴（保留）**：niche_high_quantile = 0.70 / 0.75 / 0.80 / 0.85
- **颜色编码**：FDR < 0.05 且 log2FC > 0.5 的显著 DEG 数量

每个格子现在会真正重建 k-NN 图并重新计算 niche_score，结果**每行必然不同**，热图有意义。

### 输出变化

| 文件/图 | 变化 |
|---------|------|
| `param_scan_deg_stability.csv` | 列从 `resolution/quantile/n_sig_deg/n_clusters` 改为 `k/quantile/n_sig_deg/mean_log2fc_topN/top_genes_str` |
| `plots/param_scan_deg_stability_heatmap.png` | 纵轴从 Leiden resolution 改为 kNN neighbors (k)，热图各行有意义差异 |

## 二、Layer 3 Gini Index：修复文件未输出问题

### 问题根因

原代码使用 `if not gini_df.empty` 判断，若数据集中没有基因满足 `Gini > 0.5`（原阈值过严），文件**不会被写出**，导致 `results/spatial_niche/gini_score_genes.csv` 不存在。

特别是对于 FOXP3 等稀有免疫基因，它们的 Gini 系数可能在 0.3-0.5 区间，用 0.5 的严格阈值会直接将其排除。

### 修复方案

1. **降低阈值**：`Gini > 0.5` → `Gini > 0.3`，覆盖更多稀有免疫基因
2. **始终写出文件**：移除 `if not empty` 条件，无论结果为空或非空均写出 CSV（空时仅含列头），保证文件路径可预期

### Gini Index 原理回顾

Gini 系数衡量表达量分布的**不均匀性**：
- Gini = 0：所有 spot 表达量完全均等
- Gini = 1：仅一个 spot 有表达，其余为 0

**高 Gini + niche_high 中有局灶性高表达 = 免疫抑制 niche 中高度特异的稀有基因**

CSV 列说明：

| 列名 | 含义 |
|------|------|
| `gene` | 基因名 |
| `gini` | Gini 系数（在 niche_high spot 中计算） |
| `log2_fc` | log2 倍数变化（仅保留 log2FC > 0 的基因） |
| `mean_high` | niche_high spot 中的均值表达量 |

文件按 `gini` 降序排列，最顶部为最局灶性表达的基因。

### 三层联合解读

| 分类 | 条件 |
|------|------|
| **核心 signature 基因** | 三层均命中（FDR<0.05 + AUC>0.6 + Gini>0.3） |
| **强候选基因** | 任意两层命中 |
| **弱候选基因** | 仅一层命中，需独立验证 |
