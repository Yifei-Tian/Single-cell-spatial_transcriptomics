# run_spatial_niche_analysis.py — 特征基因提取模块修改说明

## 问题根因分析

**为什么 FOXP3 等目标基因未被选中，但大量 p 值/FDR 很小？**

这是 Visium 空间转录组数据的经典**细胞稀释效应（Dilution Effect）**：

| 现象 | 原因 |
|------|------|
| FDR 极小（< 0.001）但目标基因未入选 | FDR 小的基因大多是高表达管家基因（如胶原蛋白、代谢酶），它们的绝对均值差异大，Wilcoxon 轻易显著，把前 Top-N 位置全占了 |
| FOXP3 的 log2FC 接近 0 | Visium 每个 spot 含 5-50 个细胞，绝大多数 spot 检测不到 Treg，FOXP3 在两组均值都 ≈ 0，ratio ≈ 1，log2FC ≈ 0 |
| Wilcoxon 秩并列失效 | 当两组数据大量是 0 时，排名密集并列，p 值失去区分能力 |

---

## 解决方案：三项核心修改

### 1. 新增检出率指标（核心修复）

在 `_rank_niche_genes` 中新增：
- **`frac_high`** / **`frac_low`**：各组中能检出该基因（表达 > 0）的 spot 比例
- **`delta_frac`**：检出率差值（不依赖均值大小，直接衡量 niche 富集程度）

> FOXP3 在 niche_high 中可能 30% 的 spot 能检出，在 niche_low 中只有 3%，`delta_frac = 0.27` 即使 log2FC 接近 0 也能被发现

### 2. 综合排序分（composite_score）

```
composite_score = 0.5 × MinMax(log2FC) + 0.5 × MinMax(delta_frac)
```

两个维度归一化后等权重融合，让稀有但富集的免疫基因能排到 Top-N。

筛选条件也升级为：
- **主条件**：FDR < 0.05 且（log2FC > 0.5 **OR** delta_frac > 0.10）
- **补充条件**：FDR < 0.2 且（log2FC > 0.3 **OR** delta_frac > 0.05）

### 3. Layer 2 强制合并（保底机制）

满足 **AUC > 0.6 且 delta_frac > 0.05** 的先验基因（FOXP3、TGFB1、FAP 等），即使通不过 Layer 1 的 FC 筛选，也会被强制并入最终签名列表。

### 4. 新增可视化：检出率散点图（`niche_fraction_scatter.png`）

横轴 log2FC、纵轴 delta_frac，四色编码：
- 🔴 红色：同时满足 FC 和 Fraction 阈值（双重显著）
- 🟠 橙色：仅 delta_frac 高（稀有免疫基因的正确位置）
- 🔵 蓝色：仅 FC 高（可能是管家基因）
- ⚫ 灰色：不显著

在这张图里，FOXP3 等目标基因将出现在**右侧或上方**（橙色/红色），清晰可见其 niche 富集特异性。
