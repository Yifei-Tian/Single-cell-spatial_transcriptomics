# 小院士的修改内容

本次对肝癌空间转录组分析流程进行了三项核心升级，涉及签名基因筛选逻辑、CHC20 验证评分体系，以及全部文档注释的同步更新。

---

## 一、签名基因筛选升级（`run_spatial_niche_analysis.py` Step 14）

### 1.1 Layer 1 筛选条件改动

| 项目 | 旧版 | 新版 |
|---|---|---|
| FDR 阈值 | `< 0.05` | `< 0.1` |
| AUC 阈值 | 无 | `> 0.60`（新增） |
| FC 阈值 | `log2FC > 0.5` | `log2FC > 0.3` |
| delta_frac 阈值 | `> 0.10` | `> 0.10`（保留） |
| 自动放宽逻辑 | 无 | 基因数 < 80 时放宽至 `FDR<0.2, AUC>0.55, FC>0.2 OR Δfrac>0.05` |
| 排序评分 | `composite_score = 0.5×norm(FC) + 0.5×norm(Δfrac)` | `signature_rank_score = 0.35×minmax(FC) + 0.35×minmax(Δfrac) + 0.30×minmax(AUC)` |

### 1.2 非特异性基因过滤（新增）

引入 350+ 个基因黑名单，过滤以下七类非特异性基因，避免其混入签名：

| 类别 | 代表基因 |
|---|---|
| 管家基因 | ACTB、GAPDH、B2M、HPRT1 等 |
| 核糖体蛋白 | RPS\*、RPL\* 系列 |
| 线粒体基因 | MT-\* 系列 |
| 血红蛋白基因 | HBA1、HBA2、HBB 等 |
| 细胞周期基因 | MKI67、TOP2A、PCNA、CDK1 等 |
| 广谱炎症基因 | IL6、TNF、CXCL8 等（过于宽泛） |
| 组织损伤基因 | HMGB1、S100A8/A9 等（过于宽泛） |

### 1.3 输出列变化

ranked CSV 新增 `auc` 和 `signature_rank_score` 列，移除旧版 `composite_score` 列：

```
gene / mean_high / mean_low / log2_fc / frac_high / frac_low /
delta_frac / auc / signature_rank_score / pvalue / fdr
```

### 1.4 参数扫描热图筛选颜色标准更新

| 旧版 | 新版 |
|---|---|
| `FDR<0.05 且 log2FC>0.5` 的 DEG 数 | `FDR<0.1 且 AUC>0.60 且 FC>0.3` 的 DEG 数 |

## 二、Figure 5 CHC20 验证评分升级（`paper_plot_functions.py` + `run_paper_figures.py`）

### 2.1 评分体系变化

| 项目 | 旧版 | 新版 |
|---|---|---|
| 评分数量 | 单一 `hcc4r_signature_score` | 三套评分（免疫模块 + 基质模块 + 组合） |
| 计算公式 | 所有签名基因均值表达 | 见下表 |
| 输出图表 | Fig.5A 投影图 + Fig.5B 对比小提琴 | Fig.5A/5B/5C 空间图 + Fig.5D 对比小提琴 |

**三套新评分公式：**

| 评分名称 | 公式 | 生物学含义 |
|---|---|---|
| `immune_signature_score` | mean(E_ig，g ∈ 免疫模块基因) | Treg/TAM 介导的免疫抑制强度 |
| `stromal_ECM_signature_score` | mean(E_ig，g ∈ 基质模块基因) | CAF/ECM 重塑介导的屏障效应 |
| `immune_stromal_niche_score` | z(immune) + z(stromal) | 综合 niche 强度（双轴 Z-score 之和） |

其中 E_ig 为 log1p-normalized(10k) 表达量，z(·) 为跨 spot 的 Z-score 标准化。

### 2.2 新增绘图函数（`paper_plot_functions.py`）

| 函数 | 输出文件 | 说明 |
|---|---|---|
| `compute_dual_module_scores()` | — | 计算三套评分，返回 5 元组 |
| `_spatial_score_plot()` | — | 内部通用空间投影函数 |
| `plot_fig5A_immune_spatial()` | `fig5A_chc20_immune_module_score.png` | 免疫模块空间图 |
| `plot_fig5B_stromal_spatial()` | `fig5B_chc20_stromal_ECM_module_score.png` | 基质模块空间图 |
| `plot_fig5C_combined_niche_spatial()` | `fig5C_chc20_combined_niche_score.png` | 组合 niche 空间图 |
| `plot_fig5D_comparison_violin()` | `fig5D_combined_score_HCC4R_vs_CHC20.png` | HCC4R vs CHC20 对比图（Mann-Whitney U） |

旧版函数（`compute_signature_score`、`plot_fig5A_signature_projection` 等）保留为向后兼容，不再作为默认调用。

### 2.3 模块基因来源（`run_paper_figures.py` 中 `_split_module_genes()`）

优先级由高到低：

1. 从 `immunosuppressive_niche_signature_genes_ranked.csv` 的 `module` 列自动读取（`"immune"` / `"stromal"`/`"ecm"`）
2. 使用内置先验基因列表：
   - 免疫模块 21 个：FOXP3、IL2RA、CTLA4、TIGIT、IKZF2、TNFRSF18、IL10、TGFB1、PDCD1、LAG3、HAVCR2、ENTPD1、CD163、MRC1、ARG1、CCL22、CCL17、VSIR、IDO1、IDO2、CXCL12
   - 基质模块 21 个：FAP、ACTA2、POSTN、COL1A1、COL1A2、COL3A1、COL4A1、VCAN、FN1、LOXL2、THBS2、SPP1、MMP2、MMP9、MMP11、SPARC、LUM、DCN、PDGFRA、PDGFRB、PECAM1

### 2.4 新增输出 CSV 文件

| 文件 | 内容 |
|---|---|
| `fig5_dual_module_scores_HCC4R.csv` | HCC4R 三列评分（免疫/基质/组合） |
| `fig5_dual_module_scores_CHC20.csv` | CHC20 三列评分（免疫/基质/组合） |
| `fig5_immune_genes_used_CHC20.txt` | CHC20 实际匹配到的免疫模块基因 |
| `fig5_stromal_genes_used_CHC20.txt` | CHC20 实际匹配到的基质模块基因 |
